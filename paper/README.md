## 매일 실행 (한국시간 09:05 이후, 하루 1번)

```bash
python3 -m trading.paper run
```

- 신호: 직전에 완성된 일봉 종가 기준. 체결: 실행 시점 현재가 + 슬리피지 0.1% + 수수료 0.05%
- 백테스트 체결가(오늘 봉 시가)와의 차이를 `gap_vs_open`으로 기록
- 같은 날 두 번 실행해도 주문하지 않음. 계좌마다 하루 주문 1회
- 데이터 이상(조회 실패, 마지막 봉 날짜, 날짜 누락, 가격 0 이하) → 아무것도 하지 않고 `log.jsonl`에 기록
- **비상 정지**: `paper/STOP` 파일을 만들면 모든 주문 거부
- 계좌 손실 -40% → 그 계좌 정지, 재검토

## 재검토 기준 (미리 정함)

- 어떤 계좌든 -40% 도달
- 백테스트 체결가와 모의 체결가 차이 평균이 0.3% 초과
- 최소 3개월 운영. 그 기간 성과로 전략·파라미터를 바꾸거나 실전 근거로 쓰지 않음 (목적은 운영 검증)

## 파일

- `state/<계좌>.json` 계좌 상태와 거래 기록
- `log.jsonl` 모든 판단과 사유
- `summary.json` 상황판용 요약
