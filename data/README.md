# 데이터 폴더

백테스트에 쓸 일봉 CSV를 여기에 넣습니다.

```
date,open,high,low,close,volume
2024-01-02,35000,35500,34800,35200,1234567
```

- 한글 헤더(`일자,시가,고가,저가,종가,거래량`)와 `2024.01.02`, `20240102` 같은 날짜 형식도 읽을 수 있습니다.
- 숫자 안의 쉼표(`"1,100"`)도 괜찮습니다.
- `sample_synthetic.csv`는 **가짜(합성) 데이터**입니다. 코드가 잘 돌아가는지 확인하는 용도일 뿐, 실제 시장과 관계없습니다.

실제 데이터 구하는 법: 증권사 앱이나 HTS에서 일별 시세를 내보내기(CSV)하거나,
이 환경의 네트워크에서 데이터 사이트를 허용한 뒤 받아옵니다.
