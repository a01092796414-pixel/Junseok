# 마주톡 (Talk Bridge)

아이폰에서 쓰는 한국어 ↔ 영어 실시간 대화 번역 웹 앱입니다.
휴대폰 하나를 테이블에 놓고 위쪽(뒤집힌 화면)은 영어 사용자, 아래쪽은 한국어 사용자가 씁니다.

## 기능
- 마이크를 누르고 말하면 **말하는 도중에도** 상대 쪽에 번역 텍스트가 바로 뜹니다 (점선 말풍선).
- 말을 잠깐 멈추면(약 1.2초) 문장이 확정되고 다시 번역해서 정리합니다.
- 마이크를 끄면 번역된 문장을 소리로 읽어 줍니다. 말풍선을 누르면 다시 읽어 줍니다.
- 글자로 입력해도 됩니다.
- **사투리**: 설정 › 내 한국어 말투에서 지역을 고르면 Claude가 그 사투리로 알아듣고 번역합니다.
- **단어장** (`단어장` / `Words` 버튼): 신조어, 경상도·전라도·충청도·제주도 사투리, 영어 슬랭의 뜻을 찾아볼 수 있고
  내 단어를 추가·삭제할 수 있습니다. 번역할 때 단어장의 말이 나오면 그 뜻대로 옮깁니다.
  기본 단어 목록은 `words.js` 에 있습니다. 무료 번역을 쓸 때는 한국어 쪽 단어를 뜻으로 바꿔서 보냅니다.
- 음성 인식이 잘못 받아 적었으면 **내 말풍선을 눌러 고친 뒤** 다시 보내면 다시 번역합니다.
- `복사` 버튼으로 대화 내용을 원문과 번역 함께 복사할 수 있습니다.

## 혼자 쓰기 모드 (Solo)
외국인 학생이 혼자 쓰는 화면입니다. 가운데 줄의 `혼자 쓰기 · Solo` 버튼으로 바꾸고, 안내는 영어로 나옵니다.
- **Listen to Korean**: 주변 한국어(수업, 대화, 안내 방송)를 들으면서 영어로 바로 보여 줍니다.
- **Speak English**: 영어로 말하면 한국어로 바꿔 줍니다. 한국어 카드를 누르면 전체 화면으로 크게 띄워서 한국 사람에게 보여 줄 수 있고, 소리로도 들려줍니다.
- 글자로 입력하면 한글이 있으면 한국어→영어, 없으면 영어→한국어로 자동 번역합니다.
- `Polite Korean`(존댓말, 기본) / `Casual Korean`(반말) 을 고를 수 있습니다.
- 마지막으로 쓴 모드를 기억합니다.

## 번역 엔진
| 단계 | 키 없음 | Claude API 키 있음 (설정에서 입력) |
|---|---|---|
| 말하는 중 (실시간 미리보기) | 무료 번역 (Google 번역 공개 주소) | 무료 번역 |
| 문장 확정 | 무료 번역 | Claude (기본 Haiku 5.5, Sonnet 5.5 / Opus 5.5 선택 가능) |

무료 번역은 Google 번역의 비공식 공개 주소를 쓰고, 막히면 MyMemory로 넘어갑니다. 공식 서비스가 아니라서 언제든 막힐 수 있습니다.
API 키는 아이폰 브라우저에만 저장되고 Anthropic에만 전송됩니다.

## 아이폰에서 쓰는 법
1. 이 폴더를 HTTPS 주소로 올립니다 (아래 "배포" 참고).
2. 아이폰 Safari로 주소를 엽니다.
3. 공유 버튼 › **홈 화면에 추가** 를 누르면 앱처럼 쓸 수 있습니다.
4. 처음 마이크를 누르면 마이크·음성 인식 허용을 물어봅니다 → 허용.
   - 음성 인식이 안 되면: 설정 › Siri 켜기, 설정 › 일반 › 키보드 › 받아쓰기 활성화 켜기.

## 배포
음성 인식은 HTTPS에서만 동작합니다. 방법 중 하나를 고르세요.
- **GitHub Pages**: 저장소를 Public으로 바꾸거나 GitHub Pro를 쓰는 경우 Settings › Pages 에서 이 브랜치의 루트(`/`)를 선택.
- **Netlify Drop** (https://app.netlify.com/drop): `index.html`, `words.js`, `manifest.webmanifest`, `icons/` 를 한 폴더에 담아 끌어다 놓기.
  고친 뒤 다시 올릴 때는 Netlify 사이트의 Deploys 화면에 새 폴더를 끌어다 놓으면 주소는 그대로 유지됩니다.

## 파일
- `index.html` — 아이폰용 앱 본체
- `words.js` — 기본 단어장 (사투리 · 신조어 · 영어 슬랭)
- `manifest.webmanifest`, `icons/` — 홈 화면 아이콘
- `app/translator.html` — claude.ai 아티팩트 버전 (데스크톱 Chrome용)
