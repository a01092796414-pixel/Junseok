# 마주톡 (Talk Bridge)

한국어 ↔ 영어 실시간 대화 번역 웹 앱입니다. 휴대폰 하나를 테이블에 놓고
위쪽(뒤집힌 화면)은 영어 사용자, 아래쪽은 한국어 사용자가 씁니다.

- 마이크 버튼을 누르고 말하면 상대 쪽에 번역된 문장이 크게 뜨고 소리로 읽어 줍니다.
- 글자로 입력해도 됩니다.
- 번역된 말풍선을 누르면 다시 읽어 줍니다.

## 파일
- `app/translator.html` — 앱 본체 (Claude 아티팩트로 게시된 버전)
- `index.html` — 브라우저에서 바로 여는 단독 버전 (GitHub Pages용)

## 동작 방식
| 기능 | 아티팩트(claude.ai)에서 | 단독 웹(index.html)에서 |
|---|---|---|
| 번역 | Claude | MyMemory 무료 번역 API (하루 사용량 제한 있음) |
| 음성 입력 | Claude 받아쓰기 (Chrome 계열) | 브라우저 음성 인식 (Chrome, Safari) |
| 읽어주기 | 브라우저 음성 합성 | 브라우저 음성 합성 |
